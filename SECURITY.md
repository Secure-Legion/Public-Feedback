# Security vulnerability reporting

Please do not open a public GitHub issue for a suspected security vulnerability in Secure.

Report it privately to **dev@securelegion.org**. Include a clear description of the problem, the affected app/platform and version, its potential impact, and reproduction steps or a proof of concept if you can share them safely.

Do not include user secrets, private messages, recovery phrases, or third-party personal information. Do not attempt to access other people's data or disrupt services while investigating a report.

We appreciate coordinated disclosure. Please give our team an opportunity to investigate and address an issue before making exploit details public. We cannot guarantee a specific resolution timeline or offer a bug bounty through this repository.

Ordinary crashes, interface issues, and non-sensitive bugs can be reported through the [public issue tracker](https://github.com/Secure-Legion/Public-Feedback/issues/new/choose).
