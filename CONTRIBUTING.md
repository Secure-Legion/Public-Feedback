# Contributing feedback

This repository is for reports and suggestions, not app source code or general pull requests.

## Before posting

1. Search [existing issues](https://github.com/Secure-Legion/feedback/issues) for a similar report.
2. Choose the closest issue form.
3. Keep each issue focused on one problem or request.
4. Include enough detail for someone else to understand or reproduce the problem.
5. Remove sensitive information from screenshots and logs before sharing them.

Please don't post secrets, identifying contact information, private correspondence, recovery phrases, private keys, or Tor onion service addresses. GitHub issues are public and may be indexed and archived.

Report security vulnerabilities privately using the instructions in [SECURITY.md](SECURITY.md).

## How we handle reports

Maintainers may assign labels, ask follow-up questions, combine duplicates, move an issue to an appropriate source repository, or close reports that cannot be acted on. If we need information, replying in the same issue is the easiest way to help.

We don't commit to implementing every suggestion. Please avoid opening duplicate issues or repeatedly posting the same request to raise its visibility. Use reactions or add new technical details to an existing issue instead.

## Code contributions

For code changes, use the relevant [Secure Legion source repository](https://github.com/Secure-Legion) and follow its contribution guidelines. This tracker is for public-facing feedback and issue coordination.
