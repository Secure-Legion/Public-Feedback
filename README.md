# Secure — Feedback & Issues

This is the public issue tracker for [Secure](https://securelegion.org), developed by [Secure Legion](https://github.com/Secure-Legion).

Found a bug? Something confusing? Have an idea that would make Secure better? Open an issue here. We read reports from users, testers, and developers, and use them to help decide what needs fixing or improving.

This repository covers Secure on **Android and iOS**, and will also cover **desktop** as those builds become available. It does not contain the app's source code.

## Open an issue

**[Submit feedback or report a problem](https://github.com/Secure-Legion/Public-Feedback/issues/new/choose)**

Choose the form that fits:

- **Bug report:** Something is broken, crashes, or behaves incorrectly.
- **Feature request:** You want something added or changed.
- **General feedback:** Something works, but the experience could be better — or you have feedback that doesn't fit elsewhere.
- **Compatibility issue:** Secure isn't working properly on a particular device, OS version, or network setup.

Before opening a new issue, [search existing issues](https://github.com/Secure-Legion/Public-Feedback/issues). If someone has already reported the same problem, add useful details to that issue instead.

## What to include

For bugs, tell us what happened, what you expected, and how to reproduce it. Include your platform, OS version, and Secure app version if you know them.

Screenshots and logs can help, but **review them before posting**. This is a public repository. Do not post recovery phrases, private keys, passwords, private conversations, contact details, personal identifiers, .onion addresses, or anything else you do not want publicly accessible. If a report cannot be made safely without sensitive material, contact us privately instead.

## Security vulnerabilities

**Do not report exploitable security vulnerabilities in public issues.**

Email **[dev@securelegion.org](mailto:dev@securelegion.org)** with the details. See [SECURITY.md](SECURITY.md) for disclosure guidance.

## What happens after you submit

We review incoming issues, ask for more detail when needed, and label them so people can follow their status. Some issues will be fixed quickly; others may take longer or may not fit our plans. An issue being open does not guarantee a change or a release date.

You can follow [open issues](https://github.com/Secure-Legion/Public-Feedback/issues) and [closed issues](https://github.com/Secure-Legion/Public-Feedback/issues?q=is%3Aissue%20is%3Aclosed) here. For app builds, see [Secure releases](https://github.com/Secure-Legion/releases).
